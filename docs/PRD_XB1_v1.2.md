## 1. 背景与目标

### 1.1 背景
用 Z 哥 B1 战法做 A 股，每天手动翻 K 线看 KDJ 的 J 值、白线/黄线、量能，费时且标准不稳。B1 条件基本可量化，适合程序每天固定跑一遍。

### 1.2 产品定位（v1.1 的核心变化）
v1.0 是“一个本地脚本 + 定时任务”。v1.1 改为 **“Skill = 确定性引擎，Agent = 触发器 + 展示层”**：

| 角色 | 负责 | 不负责 |
|---|---|---|
| **Skill（Python）** | 取数、指标、信号判定、评分、报告生成、结果落盘、输出精简摘要 | 定时、推送、与用户对话 |
| **Agent（WorkBuddy / Claude 等）** | 定时调用 Skill；把 Skill 输出**原样**呈现给用户；按用户追问调用 Skill 的查询子命令；可选地把结果推送到飞书等 | 计算任何指标；判断任何信号；改写任何数字 |

### 1.3 两个核心目标
1. **消除幻觉**：所有数字、信号、等级只来自 Python 输出。Agent 没有机会“估算”或“补全”，因为它根本看不到原始 K 线，只看到已经算好的结果。
2. **节省 Token**：原始数据（约 200 只 × 250 日 K 线，数万行）永远不进入 Agent 上下文。Agent 每次只收到 ≤ 1,000 token 的摘要；需要细节时再按需查询单只股票。

### 1.4 非目标
- 不自动下单，不对接券商。
- 不做盘中实时监控（B1 按收盘价判断）。
- 不做全市场扫描（v2 再考虑）。
- **不使用大模型判断信号**。LLM 仅可用于对结果的文字润色，且不得改动数据。

## 2. 关键设计决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 形态 | Skill + CLI，Agent 无关 | 不绑定任何一家 Agent；只要能执行 shell 就能用 |
| 运行时间 | **每个交易日 21:00（Asia/Shanghai）** | 收盘数据已稳定；报告用于**次日**开盘前的计划 |
| 复盘日期 | **T（当日收盘）** | v1.0 的 T-1 取消。21:00 已有当日数据 |
| 数据源 | **westock（腾讯自选股 CLI）为主**，baostock/AKShare 作为可选备用适配器 | 实测通过，见第 3 章 |
| 复权 | 前复权（`--fq qfq`） | 实测复权生效 |
| 调度 | 由 Agent 的定时机制触发（WorkBuddy 自动化 / Claude 定时任务）；同时提供 launchd 备用模板 | Skill 本身不含调度，保持可移植 |
| 推送 | **Agent 侧完成**（飞书 IM / 文档 / 多维表格等连接器）；Skill 自带可选 Webhook 作为无 Agent 时的后备 | 复用 Agent 已授权的连接器，Skill 里不存密钥 |
| 幂等 | 同一交易日已成功则直接返回上次结果（不重算） | 避免重复推送、重复耗时 |
| 输出契约 | 固定 JSON schema + 预渲染文本，带数据日期、版本号、校验摘要 | 让 Agent 只做转述 |

## 3. 数据源实测结论（2026-11-03）

对 westock v0.0.9（已安装并授权）做了实测，用 sz300124/sh601100/sh688017/sz002979/sh600519 等样本。

| 验证项 | 结果 | 备注 |
|---|---|---|
| 250 日前复权日 K | ✅ | 单只约 0.5 秒；字段：date/open/last(收)/high/low/volume/amount/exchange(换手)/change_pct |
| 复权生效 | ✅ | 茅台 250 日前：qfq 1406.72 / nofq 1458.70 / hfq 9720.00 |
| 批量取数 | ✅ 但**上限 20 只/次** | 超过直接报错；20 只 × 250 日约 3 秒 |
| 概念板块成分股 | ✅ | `search <名> --type sector` → `sector constituent <代码>`；“人形机器人”(pt02GN2238) 468 只 |
| 行业板块 | ✅ | 申万二/三级可搜，如 pt01801093 汽车零部件 |
| 交易日历 | ✅ | `trade-calendar`，官方接口 |
| 指标口径 | ✅ | 按通达信口径自算 KDJ(9,3,3)（SMA、K/D 初值 50），与 `westock technical` 的 J 值对比：5 只 × 30 日，**最大误差 0.000** |
| **限流** | ⚠️ | 无间隔连发 24 批，7 批整批 `LOCAL_RATE_LIMITED`（128/468 只失败）；限流非固定阈值（后续无间隔 12 批全过），详见 `WESTOCK_NOTES.md` 第 6 节 |
| ST 标记 | ⚠️ 无专用字段 | 用名称前缀 `ST`/`*ST`/`退` 判断 |
| 停牌标记 | ⚠️ 无专用字段 | 最后一根 K 线日期 ≠ 当日交易日则视为停牌/未更新 |
| 上市日期 | ✅ | `profile` 的 `listedDate` |
| 振幅 | ⚠️ 无字段 | 自算：(最高−最低)/昨收 |
| 白线/黄线/BBI | ⚠️ 无字段 | 自算（公式见 4.3） |

> 安装、授权、命令、输出格式、踩坑的完整记录见 `docs/WESTOCK_NOTES.md`。

### 3.1 对实现的约束（必须遵守）
1. 批大小固定 **20**；批间隔默认 **1.5 秒**（可配置）；遇 `LOCAL_RATE_LIMITED` 等待 30 秒后只重试**该批**，最多 3 次。
2. 输出是 Markdown 表格，数据层统一用一个解析函数转 DataFrame，**解析失败要抛错而不是返回空**。
3. 批量返回部分失败时，逐只记录失败原因，不影响其他股票。
4. 增量缓存：每只股票保存 parquet，每天只补拉缺失日期（有缓存时一次运行主要是 1 个 K 线点，可降到 ~1 分钟内）。
5. 备用源接口先定义（`DataProvider` 抽象类），v1 只实现 westock；baostock/AKShare 作为后续适配器，不阻塞上线。

## 4. 功能需求

### 4.1 F1 股票池
输入方式取并集后去重：

| 方式 | 说明 |
|---|---|
| 股票清单 | `config.yaml` 中的 6 位代码 |
| 概念/行业板块 | 配板块名，运行时自动搜索代码并取成分股；**成分股缓存 7 天**，减少请求 |
| 外部文件 | CSV/TXT，每行一个代码 |

自动剔除（可配置）：ST/*ST/退市整理（名称判断）、停牌、上市 < 120 个交易日、北交所（`bj` 前缀）。

### 4.2 F2 数据获取
- 每只 250 个交易日前复权日 K，增量缓存，批量+限流策略见 3.1。
- **盘中防误跑（实测发现）：** 交易时段内当日 K 线会实时变动，仅凭日期无法判断是否收盘。交易日 15:30 前运行 `run`，默认拒绝并提示（退出码 `30`），`--allow-intraday` 时在摘要首行标注“盘中数据，非收盘结论”。
- 校验：最后一根 K 线日期必须等于“今日交易日”，否则标记“数据未更新”；**整体超过 20% 未更新则等待 10 分钟重试，最多 3 次**，仍失败则返回错误状态（不输出残缺信号）。

### 4.3 F3 指标计算（纯函数）
| 指标 | 公式 |
|---|---|
| 白线 | `EMA(EMA(C,10),10)` |
| 黄线 | `(MA14+MA28+MA57+MA114)/4` |
| BBI | `(MA3+MA6+MA12+MA24)/4` |
| MA60 | `MA(C,60)` |
| KDJ(9,3,3) | RSV 用 9 日最高/最低；`K=SMA(RSV,3,1)`，`D=SMA(K,3,1)`，`J=3K-2D`；**K/D 初值 50**；等价 `ewm(alpha=1/3, adjust=False)`，勿用简单均线 |
| MACD(12,26,9) | 标准，v1 仅展示 |
| 振幅 | `(H-L)/昨收` |

### 4.4 F4 B1 判定（阈值全部来自 config）
**趋势闸门（全部满足）**：G1 白线>黄线；G2 收盘≥黄线（允许跌破，连续不超过 2 天）；G3 MA60 较 5 日前上升；G4 近 14 日最大成交额≥1.5 亿。
**触发**：T1 `J ≤ 13`。
**质量评分（满分 100）**：Q1 J<-5 得 20；Q2 缩量（≤20 日最大量×0.5 得 10，×0.3 得 20）；Q3 |涨跌幅|<2% 得 15；Q4 振幅（主板<4%，创业板/科创板<7%）得 15；Q5 收盘贴近白线（≤3%）或在其上得 10；Q6 近 10 日无高位放量阴线得 10；Q7 近 30 日有放量上涨段（≥15%）得 10。
**分级**：⭐完美 B1（≥75 且 Q1、Q2 满足）／标准 B1（50–74）／观察（过闸门且 13<J≤20）／不符合。

> “高位放量阴线”：收阴、跌幅≥4%、量≥前 5 日均量×2、收盘在近 60 日高点 85% 以上。

### 4.5 F5 B1 确认
过去 3 个交易日内出现过标准及以上 B1，且当日：收阳；涨幅≥3% 或量≥前 5 日均量×1.5；收盘站上白线（或 BBI）。

### 4.6 F6 交易计划辅助
参考买入价=当日收盘；止损=max(B1 当日最低×0.99, 近期结构前低)，止损幅度>8% 标“止损过宽”；时间止损（买入后第 4 个交易日未涨）；站上 BBI 后两根中大阳线止盈一半；连续 2 日跌破 BBI 或白线下穿黄线离场；单只仓位≤20%。

### 4.7 F7 全清单总览与预警
全部股票的趋势状态（多头/破位）；预警：白线刚下穿黄线（牛绳断）、连续 2 日跌破 BBI；数据异常（失败/停牌/未更新）。

#### 5.1.1 `data/` 子目录明细

| 路径 | 内容 | 生命周期 | 可否删除重建 |
|---|---|---|---|
| `data/raw/kline/{代码}.parquet` | 每只股票的前复权日 K 线（增量追加），即“收集的数据” | 永久，每日只补缺失日期 | 可（重拉约 5–8 分钟） |
| `data/raw/universe/{板块代码}_{YYYY-MM-DD}.json` | 板块成分股快照（含抓取时间） | 保留 90 天 | 可 |
| `data/raw/calendar/trade_calendar.json` | 交易日历缓存 | 每周刷新 | 可 |
| `data/raw/profile/{代码}.json` | 名称、上市日期、板块归属 | 每周刷新 | 可 |
| `data/cache/indicators/{代码}.parquet` | 指标缓存（白线/黄线/KDJ 等），由 K 线派生 | 随 K 线更新 | 可（纯派生） |
| `data/runs/{YYYY-MM-DD}/signals.json` | **全部股票**的完整指标与命中条件，供 `explain`/`list` 读取 | 保留 365 天 | 不建议（可用 `--force` 重算） |
| `data/runs/{YYYY-MM-DD}/brief.md` | 预渲染摘要（Agent 看到的内容原文） | 保留 365 天 | 同上 |
| `data/runs/{YYYY-MM-DD}/meta.json` | 数据日期、引擎版本、配置哈希、股票池大小、校验码、耗时、退出码、westock 版本 | 同上 | 同上 |
| `data/runs/{YYYY-MM-DD}/fetch_errors.json` | 本次取数失败/限流/停牌明细 | 同上 | — |
| `data/reports/{YYYY-MM-DD}/b1_report.xlsx` | 完整 Excel 报告 | 永久 | 可重算 |
| `data/reports/{YYYY-MM-DD}/b1_report.md` | 完整 Markdown 日报 | 永久 | 可重算 |
| `data/reports/{YYYY-MM-DD}/b1_cards.html` | K线卡片 · B1 信号视图（每只信号股一张日 K 线卡片，自包含 HTML） | 永久 | 可重算 |
| `data/reports/{YYYY-MM-DD}/kline_cards[-视图].html` | K线卡片（全部股票，`kline` 生成，含无信号，按等级排序） | 永久 | 可重算 |
| `data/reports/latest` | 指向最近一次报告目录的软链接 | — | 可 |
| `data/history/signals.parquet` | 每日信号流水（日期、代码、等级、得分、J、止损价…），**回测底座** | 永久，只追加 | **否，务必备份** |
| `data/history/outcomes.parquet` | T+3/5/10 收益回填结果（`backfill` 产生） | 永久 | 可由 signals+raw/kline 重算 |
| `data/logs/run-{YYYY-MM-DD}.log` | 单次运行日志：股票池大小、失败列表、耗时、退出码 | 保留 90 天 | 可 |
| `data/logs/westock-{YYYY-MM-DD}.log` | westock 调用记录（命令、耗时、是否限流，不含凭证） | 保留 30 天 | 可 |
| `data/state/state.json` | 每个交易日的运行状态（success/failed）与最后成功日期，用于幂等 | 永久 | 可 |
| `data/state/run.lock` | 运行锁，防止 21:00 自动化与手动运行并发 | 运行期间存在 | 可 |

**分类原则（用于判断某个文件该放哪里）：**
- `raw/`：从外部取回来的、未加工的原始数据。**只追加**，不手工编辑。
- `cache/`：可由 raw 重新算出的派生物，删了不丢信息。
- `runs/`：某一次执行的过程产物，按“数据日期”分目录，便于逐日追溯和复现。
- `reports/`：给人看的最终成品。
- `history/`：跨日累积、价值随时间增长的数据，**唯一需要重点备份的目录**。

#### 5.1.2 路径约定（实现要求）
1. **根目录解析优先级**：环境变量 `XB1_HOME` > 命令行 `--home` > 脚本自身位置向上两级（`scripts/` 的上一级）。默认即 `/Volumes/work/Workspace/XB1/`。
2. 所有路径只能通过 `paths.py` 获取，**业务代码中禁止出现硬编码路径或 `~`**。
3. `SKILL.md` 与摘要中展示的路径一律使用**绝对路径**（Agent 与用户可直接打开）。
4. 启动时检查根目录所在卷已挂载（该目录在 `/Volumes/work`，外置卷未挂载时 `run` 返回退出码 `50` 并提示“工作卷未挂载”，不得在别处新建同名目录）。
5. 写文件一律“先写临时文件再原子重命名”，避免中途中断留下残缺报告。
6. 可配置 `retention`（天数）并提供 `xb1.py gc` 清理过期的 `runs/`、`logs/`、`raw/universe`；`history/` 永不自动清理。
7. 建议磁盘预算：`raw/kline` 约 200 只 ≈ 20 MB，468 只 ≈ 50 MB；每日 `runs` 约 2–5 MB；一年总量预计 < 2 GB。所在卷当前空闲约 25 GB，足够。
8. 备份建议：每周把 `data/history/` 与 `config.yaml` 复制到另一位置（可作为后续里程碑自动化）。

### 5.2 CLI 子命令
| 命令 | 用途 | Agent 获得的输出 |
|---|---|---|
| `xb1.py doctor` | 检查 westock 安装/授权、依赖、配置 | ≤10 行状态 |
| `xb1.py run [--date D] [--force] [--format brief\|json]` | 执行完整复盘；幂等 | **brief 摘要（见 5.3）**，完整文件落盘到 `data/` |
| `xb1.py latest [--format]` | 读取最近一次结果，不重算 | 同 run |
| `xb1.py explain <代码> [--date D]` | 单只股票的指标、命中条件、扣分项 | ≤300 token |
| `xb1.py list <confirm\|perfect\|standard\|watch\|warn>` | 按类别列出完整名单 | 表格 |
| `xb1.py backfill` | 回填历史信号的 T+3/5/10 收益 | 汇总统计 |
| `xb1.py config [get\|set]` | 查看/修改阈值，无需改代码 | 当前值 |

退出码：`0` 成功；`10` 非交易日（正常，不算失败）；`20` 数据源不可用；`30` 数据未更新；`40` 配置错误；`50` 工作卷未挂载/目录不可写；`1` 其他。Agent 根据退出码决定“静默/告警”，**不靠解析文字判断**。

### 5.3 输出契约（防幻觉 + 省 Token 的关键）
`run --format brief` 的 stdout 是一段**已经渲染好的 Markdown**，Agent 直接转述：

```
【B1 复盘】数据日期 2026-11-03（周二）｜股票池 186｜引擎 v1.1.0｜校验 a3f9c1
结论：B1确认 2 ｜ 完美B1 1 ｜ 标准B1 4 ｜ 观察 7 ｜ 预警 3

🔥 B1 确认
| 代码 | 名称 | 得分 | 收盘 | J | 止损 | 止损幅度 | 命中 |
...（每类最多 N 条，默认 10；超出显示“另有 X 只，见 list 命令”）

⚠️ 预警：牛绳断 2（xxx、yyy）｜连续破 BBI 1（zzz）
数据异常：失败 0｜停牌 3｜未更新 0
完整报告：/Volumes/work/Workspace/XB1/data/reports/2026-11-03/b1_report.xlsx
K线卡片：/Volumes/work/Workspace/XB1/data/reports/2026-11-03/b1_cards.html
免责声明：仅供复盘参考，不构成投资建议。
```

同时落盘 `data/runs/{日期}/signals.json`（含全部股票完整指标），Agent 不需要读它。

| 内容 | 谁产生 | Token 量级 |
|---|---|---|
| 原始 K 线（~200×250 行） | Python 内部处理，**不输出** | 0 |
| brief 摘要 | Python 预渲染 | 约 600–1,000 |
| 单只 explain | Python | 约 300 |
| SKILL.md 本身 | 人写，极简 | 约 600–800（仅触发时加载） |

对比：让 Agent 自己拉 200 只 K 线再分析，仅数据就是 20 万+ token，且结论不可复现。

### 5.4 SKILL.md 必须包含的硬规则（给 Agent 的约束）
1. 触发词：B1、选股复盘、白线黄线、J 值超卖、“跑一下今天的 B1”等。
2. **只通过 `xb1.py` 取得任何数字**；禁止自行计算指标、禁止用网络搜索代替、禁止根据记忆补全。
3. 呈现时**原样转述**摘要中的表格与数字；可以加一句话评论，但不得改动、补充或推测数据。
4. 退出码为 10：回答“今日非交易日”，不当成错误；20/30：如实告知“数据源异常/未更新”，**禁止编造结果**。
5. 用户追问某只股票：调用 `explain`，不要凭印象回答。
6. 摘要中的校验码与数据日期必须随回答一起展示，便于追溯。
7. 结尾保留免责声明。

### 5.5 Agent 侧集成（可选层，由各 Agent 自行适配）
Skill 不依赖任何连接器；以下是 WorkBuddy 上的推荐用法：

| 环节 | WorkBuddy 做法 |
|---|---|
| 定时 | 自动化：周一至周五 21:00；prompt 为“运行 XB1 的 run 命令并原样呈现结果；若退出码为 20/30 则发飞书告警”。非交易日退出码 10 静默 |
| 推送 | 飞书 IM 发 brief 摘要（Agent 只做转发，不重写） |
| 日报文档 | 可选：用飞书文档发布 `b1_report.md` |
| 历史积累 | 可选：把 `signals.json` 的信号行写入飞书多维表格，供 v2 回测 |
| 待办提醒 | 可选：对“B1 确认”股票建飞书任务，含止损价与时间止损日 |
| 公告风险 | 可选：对入选股票调用通达信连接器查近 7 天公告，仅作**附加标签**，不改变信号 |
| 失败兜底 | 退出码非 0/10 时发飞书 + 邮件 |

Claude Code/Cowork 等其他 Agent：只需能执行 `python scripts/xb1.py run` 并转述输出即可。

| 类别 | 要求 |
|---|---|
